# Reproducibility package — representation-dependence of strategic design (OWID energy dataset)
Environment: Python 3.12.3; pandas 3.0.2; NumPy 2.4.4; SciPy 1.17.1; scikit-learn 1.8.0; matplotlib 3.10.8. Master seed 20260411 (secondary seeds +1, +7 documented in code).
Input: owid_energy.csv (place at /mnt/user-data/uploads/ or edit the path in code/p1_prepare.py).
Run order (from this directory):
  python3 code/p1_prepare.py          # verification, filtering, derived indicators, coverage, dependency screen
  python3 code/p2_latent_cluster.py   # completeness counts, PCA/parallel analysis, k sweep
  python3 code/p3_stability_agreement.py  # subsample stability across k, alternative algorithms
  python3 code/p4_latent_agreement.py # latent-space comparison, classification agreement, cluster profiles
  python3 code/p5_rank_pareto.py      # ranking, weight/normalisation sensitivity, Pareto, coverage consequence
  python3 code/p6_temporal_robust.py  # transitions, dispersion, resampling, LOVO, imputation, out-of-time, rank stability
  python3 code/p7_tests_tables.py     # holdout diagnostic, Holm adjustment
  python3 code/p8_figures.py          # Figures 1-10
  python3 code/p9_tables.py           # Tables (markdown) from result files
  python3 code/p10_ablation.py        # screened vs unscreened ablation
All manuscript numbers are read from results/*.json and results/*.csv; none were typed by hand.
Note: results/*.pkl intermediate files are regenerated by the scripts.
